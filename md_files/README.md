## Project at a glance

ReWear is a web-based marketplace that allows customers to resell or exchange unused clothing items. The platform connects customers, retail partners, and administrators in a trusted environment where verified retail partners can validate product authenticity before listings are made available to buyers.

## Main user roles

- Customer
- Retail Partner
- Administrator

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT + bcrypt
