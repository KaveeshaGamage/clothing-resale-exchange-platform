# Product Backlog

This is the ordered index of ReWear epics and user stories. Priorities are relative and may be refined by the Product Owner during sprint planning. GitHub issue links are marked as pending until issues are created.

## Priority guide

- **P1 — Must have:** Required for a usable core marketplace or a critical trust workflow.
- **P2 — Should have:** Important supporting functionality.
- **P3 — Could have:** Useful enhancement that can follow the core workflows.

## Backlog maintenance

- The Product Owner orders stories by value, risk, and dependencies.
- Each story should have acceptance criteria before it is selected for a sprint.
- Replace each `TBD` with a link to its GitHub issue when that issue is created.
- Revisit priorities and estimates during refinement and sprint planning.
